# 分集管理与公开规则

## 分集操作

编辑器左侧每集均提供删除按钮。确认后移除该集与版本记录，后续集号前移；可删除全部分集，再从空白剧本开始。删除采用作者鉴权与 revision 校验，运行中的整部生成或分集续写会阻止结构删除。

点击添加分集可选择：

- 空白页：填写标题后创建空白分集。
- AI 续写：选择本人模型，填写剧情走向，结合故事设定、大纲和最近三集的内容生成一集。任务在后台运行，完成后保存正文和首个版本，可从任务中心定位结果。失败不创建空占位页；生成期间正文或相关故事资料变化时不写入过期结果。

接口为 `POST /api/scripts/:id/episodes`、`POST /api/ai/scripts/:id/episodes` 和 `DELETE /api/episodes/:id`。AI 续写操作标记为 `append-episode`，模型调用计入本人的分集生成用量。

## 资料与模板样式

标签下拉提供二十个推荐标签及当前自定义标签，支持输入后回车创建新标签，最多十个，后端继续执行长度和数量校验。

模板卡片统一摘要区域高度，底部使用次数、收藏与套用按钮对齐；标题和摘要限制展示行数。个人模板标注私有，模板库页面明确说明可见范围。

## 公开流程

剧本：作者在编辑器菜单中提交公开审核 → 管理员在内容审核中查看冻结快照并通过 → 作品进入公开广场，可通过分享链接查看。已公开作品不能重复送审，前后端均拦截；若需公开更新内容，先设为私有撤回，再提交修改后的版本。

模板：官方模板由管理员在官方模板管理中新增并上架后向登录用户开放。个人模板始终仅作者可见，目前没有个人模板公开申请入口，剧本公开不会同步公开其个人模板。

## 验证

66 项回归测试及前端构建通过。新增覆盖空白创建、后台续写与剧情输入、生成中编辑冲突、删除归属与 revision 检查、连续集号、删至空剧本和重新添加，以及已公开作品重复送审不产生新记录。隔离页面验收验证空白新增、删除、AI 续写落库、标签候选和卡片按钮对齐；未调用真实付费模型。
