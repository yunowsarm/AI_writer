# 个人模板公开与认证补全

## 个人模板

模板库 → 我的模板 → 打开模板详情 → 公开模板。确认后其他登录用户可在全部模板、公开模板中浏览、收藏和套用，不能修改或删除他人的模板。作者可撤回公开，撤回后其他用户的详情、套用及收藏展示均重新校验权限。新建及历史个人模板默认私有。公开的是完整模板资料、参数及大纲，页面确认框会说明范围。

接口：`PATCH /api/templates/:id/visibility`，请求体 `{"visibility":"public"}` 或 `{"visibility":"private"}`。模板列表新增 `kind=public`，`kind=personal` 始终只列本人模板。

## 微信

登录页微信快捷登录 → 微信授权 → 校验一次性 state 和发起浏览器 Cookie → 未关联身份自动注册 → 已关联身份复用原账号 → 创建当前窗口的 HttpOnly 会话。禁用账号不能登录，授权不能重放。原有个人中心绑定微信流程继续保留。

在项目 `.env` 配置 `WECHAT_APP_ID`、`WECHAT_APP_SECRET` 和 `WECHAT_CALLBACK`，回调指向后端 `/api/auth/wechat/callback`，并与微信平台登记的回调配置匹配。未完成配置时页面明确禁用入口，不使用模拟成功替代微信授权。

## 邮箱验证码

提供注册验证、验证码登录、验证码重置密码三个用途。验证码六位随机数字，十分钟有效，六十秒内不能重复获取；按邮箱与用途隔离，只保存 HMAC 摘要，单次使用，连续五次错误后失效。发送失败会清理未送达的凭据；接口不返回验证码，也不打印到日志。注册在验证码消费事务内创建账号；重置密码在同一事务消费验证码、更新密码并撤销所有旧会话。

接口：

- `POST /api/auth/email-code`：`email`、`purpose=register/login/reset`。
- `POST /api/auth/register`：原注册参数加 `code`；SMTP 配置完整时要求验证。
- `POST /api/auth/email-login`：`email`、`code`，沿用窗口独立会话。
- `POST /api/auth/email-reset`：`email`、`code`、`password`。

填写 `.env` 的 `SMTP_HOST`、`SMTP_PORT`、`SMTP_SECURE`、`SMTP_USER`、`SMTP_PASSWORD`、`SMTP_FROM`，修改后重启后端。原密码重置链接接口继续兼容已有邮件，登录页采用验证码流程。
