# 流式输出与管理端优化

## 初稿实时输出

此前后台任务返回 202 后，创作页仅通过轮询获取全文，文字会成段跳出。现在创建后台任务后，额外订阅 `GET /api/ai/jobs/:id/events`。

- `snapshot`：连接或重连时同步完整已有文字和实际进度。
- `delta`：模型每次返回的文字直接推送给页面。
- `phase/progress/episode`：同步阶段与已完成分集。
- `done/error/cancelled`：同步任务终态。

接口沿用窗口会话及本人任务权限。离开页面仅断开观察连接，不停止后台任务；返回后从首帧恢复。网络中断时通过任务轮询补偿、重新订阅，不创建重复任务。流连接正常时不重复轮询大段正文。

## 页面布局

全局顶栏固定在视口顶部，编辑工具栏在其下方悬浮。分集导航、AI 助手和创作输出面板使用相应偏移，避免与顶栏重叠；窄屏保留自适应布局。

## 管理后台

管理端侧栏仅保留数据看板、用户管理、官方模板、内容审核、内容治理与日志；提供返回创作工作区入口。个人 API 配置、用量和任务中心留在创作工作区。

看板趋势和题材排行统一使用 ECharts，支持悬浮详情、主题变化和尺寸调整。任务统计包含生成、评估和优化，七日趋势使用完整 UTC 自然日。

表格统一表头、行高、字号、间距和状态标签；较长内容提供悬浮查看，常用操作列固定。治理面板的三个接口独立展示错误，避免单个区域失败遮蔽全部内容。日志只展示平台管理动作，历史个人 AI 配置记录仍保留在数据库中。

## 错误原因与验证

实际业务库复现公开作品查询 `ER_OUT_OF_SORTMEMORY`。原因是大 `published_json` 与排序一起进入查询执行过程。改为先分页排序轻量 ID，再按 ID 读取公开标题并恢复顺序；修复后实际业务库两份公开作品可正常读取。

验证：62 项自动化测试通过；前端生产构建通过。测试覆盖大快照列表、权限隔离、后台流增量、断开观察不取消任务和重连恢复。页面使用独立测试库与本地模拟模型验收，未调用用户付费模型。
