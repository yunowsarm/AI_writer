# 试用体验优化（2026-10-27）

## 编辑器

- 默认阅读模式，可选择原文用于 AI 打磨；点击“开始编辑”自由编辑，再次点击“退出编辑”会先保存。
- 工具栏随文档滚动吸顶，取消段落上移/下移，保留加粗、斜体、撤销、重做、添加场景/人物和格式标准化。
- 模型输出转换 HTML 时跳过空行；旧的纯 HTML 生成稿载入编辑器时也去除额外空段。已有富文本文档中的作者手动空段保持原样。
- 段距收紧；中文斜体显式允许合成字形。切换编辑状态不触发无内容变更的自动保存。

## 灵感助手

五项操作采用 Element Plus SVG 图标：Right（续写）、ZoomIn（扩写）、Scissor（精简）、Brush（风格）、Refresh（重创作）。

流程为：选择原文 → 点击操作 → 确认选中文字/整集和补充要求 → 生成候选 → 对照原文预览 → 确认应用。普通点击操作不立即请求模型。风格要求只在改写风格中展示；复杂的评估要求放在候选弹窗中，侧栏不再堆积长文本。

## 建议逐项处理

- 评分仍绑定评估时的历史稿件，修改后展示提示，但不再禁用整份报告。
- 定位前读取最新保存内容，逐条确认引用仍存在且唯一。修改第一处后，未改动的其他引用仍可继续使用。
- 每个引用旁可“定位原文”或“优化此处”，多引用问题由作者明确选择目标。
- 引用已改动或重复时拒绝自动覆盖，提示手动选择；其他建议继续可用。
- 应用后保存新版本、标记该建议“已处理”、自动返回原报告。放弃候选也返回报告，但不标记完成。
- 单项状态保存在 `quality_issue_resolutions`，刷新可保留；不修改历史评分。

## 后台任务

右上角“任务中心”统一展示剧本生成、质量评估和其他 AI 任务，显示作品、模型、实际完成数、状态；可查看进度/结果或显式停止，并提供完成通知。

生成与评估请求传 `background: true`，服务端返回 202 和 `jobId`，任务继续在后端执行。切换路由、关闭面板或刷新浏览器不会取消任务。保留旧 SSE 模式供局部候选和兼容客户端使用。

GET `/api/ai/jobs` 返回本人任务摘要与 `progress`；GET `/api/ai/jobs/:id` 返回本人任务详情及当前增量正文。`progress` 包括 title、message、completed、total、scriptId、reportId、status 和可选 resultStatus。阶段和终态写入 `ai_jobs.progress_json`，当前增量从活动任务中读取；不在任务响应中返回 Key。

关闭后端进程/电脑会中断后台任务。服务重启将运行中记录标记为失败；已保存的完整分集仍可续生成。本版本不提供跨后端重启自动续跑，也不启动额外队列服务。

## 费用

按 DeepSeek 官方中文价格表的人民币单价估算，页面统一 `¥0.00` 格式，四舍五入两位小数。同一显示精度下峰谷相同金额合并展示。先汇总未舍入金额，再格式化，避免逐条舍入累计偏差。

官方当前价格：[DeepSeek 模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。金额仍是峰谷估算区间，以供应商账单为准；缓存统计缺失、未知模型或未知供应商不伪造费用。美元字段仅保留旧接口兼容，页面不再展示美元。

## 升级与验证

旧环境执行 `npm run migrate -w server`，增加进度字段和单项处理表，再执行 `npm run build` 并启动后端。本次本机已完成迁移。

自动化测试使用独立测试库与本地模拟模型，覆盖后台响应关闭后继续运行、实际进度、账号隔离、已处理标记、引用逐项定位、空段落与人民币计算。浏览器验收也使用模拟模型，未调用真实付费 API。
