# 创作与编辑体验调整

## 创作页

- 参数表单与输出区顶部对齐，输出区按视口设置独立高度。
- 手动拉高输入框不会拉长输出区；生成内容在输出区内部滚动。

## 编辑工作台

- 编辑、撤销、重做、保存等操作集中在顶部悬浮菜单，按实际容器宽度收纳快捷项。
- 更多菜单提供未展开的操作，包括导出、格式标准化和提交公开审核。
- 选中的原文离开焦点后仍保留高亮，便于确认 AI 的处理范围。
- 本轮新增显示绿色，删除显示红色删除线。标注属于编辑视图，不进入保存正文、公开内容或导出文件。
- 自动保存继续保护内容，本轮标注保留到手动保存或退出编辑；确认后只显示最新正文。
- 版本记录提供“对比当前稿”，可以查看历史快照到当前稿的增删变化。
- 切换分集重置该集的撤销基线，避免撤销到另一集；在同一集定位建议保留本轮记录。

## 质量建议与改写篇幅

- 按报告、问题、段落三个维度分别记录处理状态；修改一处不隐藏同条建议中的其他位置。
- 篇幅根据原文实际字数及扩写、精简、续写、改写操作计算，也可输入目标字数。
- 篇幅仅作提示：超出建议范围时显示实际字数和提醒，作者仍可直接应用。请求不再根据建议字数压低正常输出额度，保留模型服务本身的输出上限。
- 字数为去除空白后的 Unicode 字符数量，篇幅范围是写作指导，不作为费用或 Token 统计。

## 验证

### 重复段落的专用处理

- “存在高度相似的段落”以及明确要求删除重复段落的建议，显示“处理重复”，打开完整段落删除预览。
- 确认删除不调用模型；引用只用来定位，实际预览和删除完整段落，避免只删除前 120 字后留下尾句。
- 预览同时展示删除后附近正文及报告中的对照引用，作者也可以选择“保留并改写”。
- 删除前核对当前文档与版本，删除后保存版本、保留修改标注，支持进入编辑模式后 Ctrl+Z 撤销或从版本记录恢复。
- 两处对照删除其中一处后完成这条重复问题；三处以上仅记录本次处理位置，其他建议继续保留。
- 同一长段内部的分块相似引用不允许直接整段删除，避免误删未重复的信息。
- 回归与模拟验收：43 项检查通过；重复段由两处减为一处，其他台词保留，新增 AI 改写调用数为 0。

- 本地模拟模型与独立测试库验证逐处处理、标注、保存、选区和历史版本对比，不调用真实 API。
- 实际拖动主题输入框高度，从约 100px 增加到 249px 时，输出区保持 620px。
