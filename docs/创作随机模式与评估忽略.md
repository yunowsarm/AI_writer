# 创作随机模式与评估忽略

## 未完成创作删除

创作页的每条未完成作品增加删除按钮。确认后沿用 `DELETE /api/scripts/:id` 软删除剧本，先撤回公开与待审核内容，再从剧本库和恢复列表移除。正文与历史数据保留在数据库中。仅作者可操作，存在运行中的 AI 任务时返回 `409 SCRIPT_TASK_RUNNING`，需先停止任务。

## AI 随机故事设定

故事设定中点击“随机模式 · AI 填写全部参数”，使用当前选定的本人供应商与模型调用 `POST /api/ai/configuration`。模型填写剧本名称、主题、人物、背景、分类风格、自定义风格、集数、单集时长和反转要求。设定返回后可继续手动调整，点击生成按钮才创建剧本和正文。

接口沿用窗口会话、任务并发限制及模型用量记录，任务操作为 `randomize`、用量阶段为 `planning`。完整结果经字段与范围校验后通过 SSE `done.configuration` 返回，并保存为任务输出。失败时保留当前表单，离开页面会取消尚未完成的设定请求；完成的设定可从任务中心再次找回。续创作使用原设定，需新建另一部剧本后才能使用随机模式。

## 评估问题忽略与恢复

每条评估问题提供“忽略问题”，接口为 `POST /api/quality/reports/:id/issues/:issue/ignore`，请求体 `{ "ignored": true }`，恢复则传 `false`。仅报告作者可操作，校验剧本和问题归属；刷新后状态保留。

忽略独立存储在 `quality_issue_ignores`，不标记为已解决、不修改评分或正文，仅对该份报告生效。默认隐藏已忽略问题，可关闭“隐藏已忽略”显示并恢复。报告返回 `ignoredIssues` 列表。一键优化规划排除已忽略问题，忽略状态参与计划指纹；已经生成的相关候选也会在应用时被拦截，避免继续修改作者不想处理的内容。

## 验证

64 项回归测试通过，生产构建通过。覆盖删除权限及恢复列表、运行中删除拦截、随机设定字段校验和用量、忽略恢复与幂等、问题归属、一键优化排除和旧候选拦截。独立页面验收使用测试库与本机模拟模型，验证了自动填表、忽略隐藏与恢复，以及删除后的列表更新，未调用真实付费模型。

升级需执行 `migrate()` 新建忽略记录表并扩展 `planning` 用量阶段；当前工作环境已完成增量迁移，未重建业务数据。
