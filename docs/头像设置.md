# 头像设置

个人中心点击头像上的“更换”，选择 JPG、PNG 或 WebP 图片，在圆形预览中确认后点击保存头像。原图限制 5MB、1600 万像素，浏览器先按中心裁剪为 512 像素方图并压缩，再上传。取消不会覆盖已保存头像；可恢复默认的昵称首字头像。

个人中心、侧栏、右上角账号菜单及公开阅读页评论使用统一的 UserAvatar 组件。图片铺满圆形，内边距、白色边框及外描边均为零；加载失败时回退到昵称首字。保存后同步当前页面，刷新和再次登录仍保留头像。已打开的其他浏览器页面会在刷新资料后显示新头像。

后端重新解码图片、检查实际格式与解码像素，拒绝 SVG、损坏图片和格式伪装，去除元数据并统一输出 WebP。头像存入 MySQL 的 user_avatars 表，用户表的 avatar_version 用于生成带版本号的图片地址。所有修改接口只操作当前登录账号；禁用账号的图片不再公开返回。

## 接口

- `PUT /api/me/avatar`：已登录，JSON `{image}`，image 为 JPG、PNG 或 WebP 的 Base64 Data URL，原始上传字节最多 512KB，返回用户资料及 avatarUrl。
- `DELETE /api/me/avatar`：已登录，恢复当前用户默认头像，返回用户资料，avatarUrl 为 null。
- `GET /api/avatars/:id`：读取公开头像图片；仅返回启用账号的现存图片，类型为 image/webp，Cache-Control 为 no-cache，按版本生成 ETag。
- `GET /api/me`：用户资料新增 avatarUrl，未设置时为 null。

## 升级部署

停止旧服务，在项目根目录运行：

```powershell
git pull origin main
npm ci
npm run migrate -w server
npm run dev
```

构建运行方式需要在 npm start 前执行 npm run build。保留 .env 与 .local，不需要重新 setup。新增 sharp 图片处理依赖由 npm ci 安装，头像随数据库备份迁移，无额外上传目录。

## 验证

独立测试库覆盖实际图片解码、尺寸归一、未登录拒绝、用户归属、非法图片不覆盖原图、持久化资料、版本更新、禁用账号不公开及恢复默认。页面检查实际选择本地测试图片、预览、保存、刷新保留，并核对三处头像的 border 与 padding 为 0。测试图片和截图不提交到仓库。
