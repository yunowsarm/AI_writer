# 演示扫码登录

仅供本地毕业设计演示，不代表微信授权，不获取 OpenID、手机号或真实设备身份。页面入口与确认页均明确标注开发演示；真实微信登录保留独立入口。

## 本机测试

刷新登录页 → 扫码登录（开发演示） → 本机打开确认页 → 确认演示登录 → 原电脑页面自动进入工作台。

手机或确认浏览器第一次确认时创建普通演示账号，服务端在 HttpOnly Cookie 中保存随机设备凭据，再次使用同一浏览器确认时复用账号。清除 Cookie、使用无痕模式、换浏览器或换网站域名都会被视作新设备，不能用于真实身份认证。演示账号的数据与登录会话正常保存至 MySQL。

## 手机实扫

手机与电脑连接同一局域网，在 `.env` 显式配置：

```env
DEMO_QR_LOGIN=true
DEV_HOST=0.0.0.0
APP_ORIGIN=http://电脑的局域网IP:3003
NODE_ENV=development
```

退出原开发进程后，在项目根目录重新执行 `npm run dev`。电脑也必须通过上述局域网地址打开登录页，再生成二维码；不要用 127.0.0.1 生成给手机访问的链接。若系统防火墙询问访问范围，按实际测试网络决定放行；本次没有自动修改防火墙或公网暴露设置。

默认前端仍只监听 127.0.0.1，未配置 DEV_HOST 时不开放局域网。恢复本机使用可移除 DEV_HOST，并恢复原 APP_ORIGIN。

## 关闭与保护

`DEMO_QR_LOGIN=false` 可关闭入口和接口；`NODE_ENV=production` 时始终禁用，不能用开关强制开启。二维码两分钟有效、单次使用，手机确认与电脑消费使用不同凭据；仅生成该二维码的电脑可取得会话，其他浏览器不能用二维码直接登录。已有账号被禁用后不能通过演示扫码继续登录。

68 项测试及前端构建通过；已在独立测试库验证本机确认后电脑自动登录。未实际拿手机进行局域网扫码，真实网络连通性需按上述步骤验证。
